# Data Directory

The raw CICIoT2023 dataset files are not included in this repository.

Download the dataset from the official CIC/UNB page:

https://www.unb.ca/cic/datasets/iotdataset-2023.html

Place the merged CSV files in:

```text
data/raw/
```

Generated processed files should be written to:

```text
data/processed/
```

Large raw and processed data files are ignored by `.gitignore`.
